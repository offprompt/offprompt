From a cloud sandbox, an agent whose host lets it ask you a question, as Conductor and Claude Code do, puts the page's link in a question as well as in its message. A question stays in front of you until you answer it; in a Conductor cloud workspace the agent's messages with the link were folded away under the waits that followed them. The link also comes with a short line saying what it is for, rather than alone.
