# cancel_secret

Closes a [`collect_secret`](/reference/collect-secret) request that is no longer needed. Anything
already typed on the page is discarded, and the page says the request is closed.

```json
{ "request_id": "9f3c1e7a" }
```

## Input

| Field | Type | What it is |
| --- | --- | --- |
| `request_id` | string | The `request_id` `collect_secret` returned |

## Output

The request as [`await_secret`](/reference/await-secret#output) reports it, with `status:
"expired"`, or `"written"` if the values landed first.

A request whose write is under way when it is cancelled is left to the write, and the result
still says `"awaiting"`. The write decides: the request is written if the values land, and
closes if the write fails. Cancelling twice is harmless. An unknown `request_id` gets the same
error result as [`await_secret`](/reference/await-secret#output).
