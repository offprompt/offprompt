# await_secret

Waits for a [`collect_secret`](/reference/collect-secret) request that came back `awaiting`. It
long-polls for up to 60 seconds and returns as soon as the request is written or expires.

```json
{ "request_id": "9f3c1e7a" }
```

The agent needs it in two cases:

- `collect_secret` returned a link, from a [cloud sandbox](/guides/cloud-sandboxes) or because no
  browser could be opened. The agent shows the link, then waits here.
- The human interrupted a `collect_secret` that was waiting, and the request is still open.

While the status is `awaiting`, the agent calls it again.

## Input

| Field | Type | What it is |
| --- | --- | --- |
| `request_id` | string | The `request_id` `collect_secret` returned |

## Output

The same fields as [`collect_secret`'s output](/reference/collect-secret#output), without
`expires_in` and `url`: `tell_user` first once written, then `request_id`, `status`, `names`,
and once written `kept`, `emoji` and `file_keys`, then `sink` and `note`.

A request offprompt does not know is an error result:
`No offprompt request with id 9f3c1e7a. It may have expired with the server restart.` Requests
live in the server's memory only, so one from before the agent restarted offprompt is unknown,
and offprompt lets a request go an hour after its expiry time.
